# Movie benchmark

KGI-Bench-Movie provides the dataset layout and evaluation workflow for the movie-domain incremental KG integration benchmark.

- **Evaluation (this repo):** [benchmarks/kgi-bench-movie/README.md](https://github.com/ScaDS/KGI-Bench/blob/main/benchmarks/kgi-bench-movie/README.md) — environment setup, dataset download, `make eval-all`, directory layout
- **Pipeline execution:** [KGpipe `experiments/moviekg`](https://github.com/ScaDS/KGpipe/tree/main/experiments/moviekg) — running integration pipelines that produce `stage_*` outputs

See also the [CLI reference](cli.md) for `kgibench evaluate`.
